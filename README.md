# Drift Donors — данные для расширения

Снапшот базы доноров Sape, GoGetLinks и Miralinks для расширения [Drift Donors](https://seo-drift.ru/drift-donors/):
`latest.json` — манифест (версия, размер, sha256), `spi_<версия>.json.gz` — сами данные. Обновляется раз в месяц.

Автор данных и методики — линкбилдер Роман Михальчук, [seo-drift.ru](https://seo-drift.ru), [@seo_drift](https://t.me/seo_drift).
Методика оценки: https://seo-drift.ru/drift-donors/drift-score/
