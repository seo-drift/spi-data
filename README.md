# spi-data

Данные для расширения [SEO Price Inspector](https://t.me/seo_drift) — сравнение цен доноров между Sape / GoGetLinks / Miralinks прямо в каталогах бирж.

Этот репозиторий — **резервный** источник обновлений (основной — seo-drift.ru). Расширение само переключается сюда, если основной адрес недоступен.

- `latest.json` — манифест (версия, sha256, ссылка на снапшот)
- `spi_<версия>.json.gz` — сам снапшот донор-базы

Файлы обновляются автоматически из пайплайна (`pipeline/build/publish_spi.py`), вручную не редактировать.
